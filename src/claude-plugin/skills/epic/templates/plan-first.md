# Plan the workflow first

Explore the goal until you can name the work items and the roles they need, and stop there, since the workers do the work. Write the workflow in the vocabulary's terms: each role with any agent, model, effort or machine it needs, the items, the guards between them, and how the epic ends. If the goal says to start, record the workflow as a note and assign the first items. Otherwise record it as a decision that needs the user, with the workflow as its reference, and wait for the answer.
