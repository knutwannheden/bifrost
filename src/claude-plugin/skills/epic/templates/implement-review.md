# Implement and review

Assign an implementer to build and test a candidate. Ask an independent reviewer to examine the exact commit and report findings with evidence. Honor the requested review setup, such as `agent: "claude"` when the user asks for Claude. Wait for the report. For each finding you accept, record a work item and ask the implementer to address it. Ask the reviewer to verify the revised commit. End with the accepted candidate, the checks that passed, and any open items.
