# Investigate in parallel

Assign two independent lines of inquiry. Give each investigator the same question and a distinct way to test it. Pass the requested agent and effort to each investigator, such as `agent: "codex"` and `effort: "high"` for a design investigation the user wants run that way. Ask each to report observations, how they obtained them, and what remains uncertain. Wait for both reports, reconcile any disagreement, and ask the user if the next step depends on a preference. End with a recommendation and its supporting evidence.
